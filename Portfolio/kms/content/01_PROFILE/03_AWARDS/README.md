# 01_PROFILE / 03_AWARDS

수상·선정·임명 이력을 관리합니다. **1 Award = 1 Markdown**.

```yaml
---
id: award-id
type: award
title: 수상명
date: "2024-02-01"
grade: 선정
issuer: 발급/수여기관
category: award
repository: https://github.com/owner/repository # optional; README modal button
---
```

날짜는 `YYYY-MM-DD`; 일자가 확인되지 않으면 `01`을 사용합니다. 최신순 자동 정렬합니다.
